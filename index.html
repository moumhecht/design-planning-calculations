transmon_capacitance_solver

Solves for CJ, CQ, CD given target qubit/drive frequencies and coupling strength. Equations follow the dispersive transmon model.

Parameters
ratioQ  (EJQ/ECQ) 70
ratioD  (EJD/ECD) 80
ωQ target (GHz) 4.50
ωD target (GHz) 7.00
J target (MHz) −200
Solution
Set parameters and press SOLVE
